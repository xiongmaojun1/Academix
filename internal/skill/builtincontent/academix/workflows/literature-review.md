# 文献综述工作流

## 适用场景
综述类论文、研究背景调研、开题报告。

## 执行流程

### Phase 1: 搜索
```bash
# 使用 WebSearch 搜索
# 关键词：中英文各一组
# 时间范围：近 5 年优先
# 来源：arXiv、Semantic Scholar、Google Scholar
```

### Phase 2: 筛选
- 按被引次数排序
- 关注高被引论文和最新论文
- 通过引用关系扩展（前向 + 后向）

### Phase 3: 阅读与分类
- 按方法分类（方法一、方法二、...）
- 按时间分类（早期、近期、最新）
- 记录每篇论文的核心思想、优点、局限

### Phase 4: 撰写综述
```markdown
# <研究问题> 文献综述

## 摘要
<200 字概述>

## 研究背景
<问题定义和重要性>

## 研究现状
### 方法一：<方法名>
- 代表论文：[1][2][3]
- 核心思想、优点、局限

### 方法二：<方法名>
...

## 研究趋势
<近期发展方向>

## 参考文献
[1] 作者. 标题. 期刊, 年份.
```

### Phase 5: 引用检查
- 每篇引用有完整信息
- 引用格式一致（APA/IEEE/GB/T 7714）
- 不编造文献

## 检查点
- [ ] 搜索覆盖主要方向
- [ ] 分类清晰
- [ ] 每篇引用真实存在
- [ ] 引用格式一致
