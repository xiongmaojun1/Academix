# 美赛（MCM/ICM）专项规范

## 2026 年重要规则
- 论文总页数限制 **25 页**（含摘要、正文、参考文献、附录，不含 AI 使用声明附录）
- 允许使用 LLM，但必须在附录中标注使用范围和校验方式
- Summary Sheet 是独立必要页面，评委权重极高

## 评分关键维度
- 假设合理性：假设必须服务于建模
- 建模创造性：多模型对比、创新方法加分
- 结果正确性：数值物理合理，约束不违反
- 表述清晰性：逻辑连贯、可视化专业

## 可视化要求
- 获奖论文图表占比通常高达 68%
- 高清矢量格式（PDF/SVG/EPS），禁止截图
- 每张图有 caption，正文中引用和解释
- 灰度打印下仍能区分

## 题型规律
- **A 题（连续型）**：偏微分方程、物理/工程建模、优化
- **B 题（离散型）**：图论、调度、组合优化、排队论
- **C 题（数据洞察型）**：数据分析、机器学习、时序预测
- **D/E/F 题（ICM）**：运筹学、可持续性、政策分析

## 高频组合
| 问题类型 | 推荐组合 |
|---------|---------|
| 综合评价 | AHP + TOPSIS 或 AHP + 熵权 + TOPSIS |
| 预测 + 不确定性 | XGBoost + Bootstrap 置信区间 |
| 风险评估 | Logistic 回归 + 蒙特卡洛 |
| 时空预测 | ARIMA/LSTM + 空间聚类 |
| 投资/资源优化 | 预测 + 动态规划/遗传算法 |
| 文本分析（C 题）| TF-IDF + LDA + 情感分析 |

## Summary Sheet 写作
- 独立一页，不是摘要复制粘贴
- 涵盖方法亮点、关键结论、模型创新点
- 评委可能只看 Summary Sheet 就打分
