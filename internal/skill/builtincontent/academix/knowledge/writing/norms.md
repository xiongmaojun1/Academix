# 写作规范

## 基本原则清单（10 条）
1. 论文不是工作日志，不出现内部文件名、脚本名、临时目录
2. 不出现"由 AI 生成"等过程痕迹
3. 参考文献必须真实存在，不编造引用
4. 公式出现后解释符号含义
5. 图表出现前后有引导和解释
6. 图内不写长标题，标题交给 caption
7. 同类图表风格统一，颜色能灰度区分
8. 摘要覆盖每个子问题的方法和关键结果
9. 数值必须与代码输出一致
10. 章节结构跟随赛题类型

## 摘要写作清单（10 条）
1. 摘要是评委最先也最重视的部分
2. 每个子问题必须覆盖：用了什么方法、建立了什么模型、主要结果是什么
3. 不要出现复杂公式和表格
4. 不要只重述题目
5. 不要用"我们认为……""本文将……"等空泛表述
6. 中国赛摘要一般不超过两页
7. 美赛 Summary Sheet 是独立一页
8. 数值必须与正文一致
9. 先写正文，最后写摘要
10. 多次检查数值是否正确

## 正文写作清单（10 条）
1. 问题重述：不是照抄题面，而是建模者的理解和重新表达
2. 模型假设：每条假设必须有必要性说明和在正文中的引用
3. 符号说明：所有后文用到的符号在此定义，有量纲标注
4. 模型建立与求解：每个子问题独立成节
5. 结果分析与检验：数值结果 + 约束验证 + 误差分析
6. 灵敏度分析：关键参数扰动时结果如何变化
7. 模型评价与推广：优缺点、改进方向、推广场景
8. 参考文献：只引用真实存在的文献
9. 附录：核心代码
10. 连续三张以上图表中间必须有文字

## 引用格式

### APA
```
作者. (年份). 标题. 期刊名, 卷(期), 页码.
```

### IEEE
```
作者, "标题," 期刊名, vol. 卷, no. 期, pp. 页码, 年份.
```

### GB/T 7714
```
作者. 标题[J]. 期刊名, 年份, 卷(期): 页码.
```

## 章节结构

### 三问建模题
按问题展开：问题一→问题二→问题三

### 统计建模
按研究逻辑链组织：数据→方法→分析→结论

### 期刊论文
标准结构：引言→相关工作→方法→实验→结论

## 图表规范

### 数据图选择
- 趋势：折线图
- 排名：条形图 / 棒棒糖图
- 分布：箱线图 / 小提琴图 / 直方图
- 关系：散点图 / 热力图
- 对比：分组柱状图 / 指标矩阵

### 非数据图选择
- 技术路线：DrawIO
- 精确数学：TikZ
- 网络拓扑：matplotlib + networkx
- 3D 场景：生成式图片

### 输出规范
- 高 DPI 输出（300+）
- 灰度打印下仍能区分
- 颜色要能灰度区分
- 避免过度装饰
