# 优化类模型详细指南

## 选型原则

先看问题规模，再看约束类型：
- 线性目标+线性约束 → 线性规划（全局最优）
- 有整数变量 → 整数规划（NP-hard，规模受限）
- 非线性 → 非线性规划（可能局部最优）或启发式
- 多阶段 → 动态规划
- 复杂约束 → 启发式（GA/SA/PSO）

| 方法 | 规模 | 优点 | 缺点 |
|------|------|------|------|
| 线性规划 LP | 万级 | 全局最优 | 只能线性 |
| 整数规划 MIP | 百千级 | 处理整数变量 | NP-hard |
| 非线性规划 NLP | 百级 | 非线性约束 | 局部最优 |
| 动态规划 DP | 小状态空间 | 精确 | 维度灾难 |
| 遗传算法 GA | 任意 | 不需梯度 | 不保证最优 |
| 模拟退火 SA | 任意 | 逃出局部最优 | 收敛慢 |
| 粒子群 PSO | 任意 | 连续空间好 | 离散需特殊处理 |
| NSGA-II | 多目标 | Pareto 前沿 | >3 目标退化 |

## 线性规划详细指南

### 标准形式
```
minimize    c^T x
subject to  Ax <= b
            x >= 0
```

### 常见错误
- **最大化**：`scipy.optimize.linprog` 只做最小化，最大化要取负目标函数
- **约束方向**：scipy 不等式约束是 `A_ub @ x <= b_ub`，注意方向
- **变量下界**：默认 x >= 0，如果变量可为负需要显式指定

### 代码模板
```python
from scipy.optimize import linprog

# min 2x1 + 3x2
# x1 + 2x2 >= 4  →  -x1 - 2x2 <= -4
# 3x1 + x2 >= 6  →  -3x1 - x2 <= -6
c = [2, 3]
A_ub = [[-1, -2], [-3, -1]]
b_ub = [-4, -6]
result = linprog(c, A_ub=A_ub, b_ub=b_ub, method='highs')
print(f"最优值: {result.fun}, 解: {result.x}")
```

## 整数规划详细指南

### 常见错误
- **连续松弛后直接取整**：可能不满足约束，必须验证可行性
- **0-1 变量**：用 `bounds=[(0,1)]` + `integrality=[1]`（scipy >= 1.9）
- **大规模**：>1000 变量时考虑启发式

### 代码模板
```python
from scipy.optimize import milp, LinearConstraint, Bounds

# min c^T x, Ax <= b, x 整数
result = milp(c, constraints=LinearConstraint(A, -np.inf, b),
              integrality=1, bounds=Bounds(0, np.inf))
```

## 启发式算法（GA/SA/PSO）详细指南

### 必须做到
1. **固定随机种子**：`np.random.seed(42)`
2. **多次独立运行**：≥5 次，报告均值和标准差
3. **与精确解对比**：小规模时用精确算法验证
4. **不要声称全局最优**：除非有证明

### 常见错误
- **不固定种子**：结果不可复现
- **只跑一次**：随机算法结果波动大
- **不验证约束**：启发式可能生成不可行解
- **参数不调**：GA 的交叉率、变异率、种群大小都需要调

## 多目标优化

### 常见错误
- **直接加权**：不同量纲的目标不能直接相加
- **必须归一化**：先独立归一化每个目标到 [0,1]，再加权
- **Pareto 分析**：当目标冲突时，给出 Pareto 前沿供用户选择

## 组合优化防错

- **TSP/VRP**：检查子回路（MTZ 约束或 lazy constraint）
- **指派问题**：匈牙利算法适用于方阵，矩形补虚拟行列
- **背包问题**：区分 0-1/有界/无界
- **网络流**：流量守恒、容量约束、负权边检查
