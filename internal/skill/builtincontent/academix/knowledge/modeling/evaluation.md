# 评价类模型详细指南

## 选型原则

选模型不是选"最流行的"，而是选"最适合的"。问自己三个问题：
1. 指标之间有没有层级关系？→ 有：AHP/ANP；没有：TOPSIS/熵权
2. 权重怎么来？→ 有专家：AHP；纯数据：熵权；都要：组合
3. 指标能不能量化？→ 能：TOPSIS；不能：模糊综合评价

| 场景 | 推荐 | 理由 |
|------|------|------|
| 有专家经验、层次结构 | AHP | 利用专家判断矩阵 |
| 纯数据驱动 | 熵权法 | 完全客观 |
| 多方案排序 | TOPSIS | 不要求指标独立 |
| 指标难量化 | 模糊综合评价 | 处理语言变量 |
| 数据少 | 灰色关联 | 数据要求低 |
| 评价效率 | DEA | 不需要权重 |
| 指标多、高度相关 | PCA + TOPSIS | 降维后排序 |
| 主客观权重都要 | AHP + 熵权 | 组合权重 |

## AHP 详细指南

### 什么时候用 AHP
当评价对象有层级结构（目标层→准则层→方案层），且有专家可以给出两两比较判断时。

### 怎么做
1. 建立层次结构（目标→准则→方案）
2. 构造判断矩阵（1-9 标度）
3. 计算权重向量（特征值法或几何平均法）
4. 一致性检验（CR < 0.1）
5. 计算综合得分

### 常见错误
- **判断矩阵 >9×9**：一致性极难保证，拆成多级层次
- **CR ≥ 0.1 不调整**：必须调整矩阵，不能强行使用
- **权重不归一化**：权重向量归一化后求和必须 = 1
- **得分计算错误**：最终得分 = 权重向量 × 方案矩阵，不是简单加法
- **方案选择错误**：AHP 只能从已有方案中选优，不能自动生成新方案

### 代码模板
```python
import numpy as np

def ahp_weights(matrix):
    """计算 AHP 权重向量"""
    n = matrix.shape[0]
    eigenvalues, eigenvectors = np.linalg.eig(matrix)
    max_idx = np.argmax(eigenvalues.real)
    weights = eigenvectors[:, max_idx].real
    weights = weights / weights.sum()
    return weights

def consistency_ratio(matrix, weights):
    """一致性检验"""
    n = matrix.shape[0]
    RI = {1:0, 2:0, 3:0.58, 4:0.90, 5:1.12, 6:1.24, 7:1.32, 8:1.41, 9:1.45}
    lambda_max = (matrix @ weights / weights).mean()
    CI = (lambda_max - n) / (n - 1)
    CR = CI / RI[n]
    return CR
```

## TOPSIS 详细指南

### 什么时候用 TOPSIS
当需要对多个方案进行综合排序，且指标之间没有层级关系时。

### 怎么做
1. 构建决策矩阵（方案 × 指标）
2. 标准化（向量归一化或 min-max 归一化）
3. 加权（权重来自 AHP 或熵权法）
4. 计算正理想解和负理想解
5. 计算距离和贴近度
6. 排序

### 常见错误
- **方案太少**：必须有 2+ 方案
- **不标准化**：欧氏距离对量纲敏感，必须先标准化
- **贴近度误解**：C = D⁻/(D⁺+D⁻)，越接近 1 越优；C 值不是百分制得分
- **指标重复计数**：高度相关指标会重复计数，用 PCA 降维后再做

## 熵权法详细指南

### 什么时候用熵权法
当希望权重完全由数据决定，不引入主观判断时。

### 常见错误
- **所有值相同**：熵权 = 0（正常，不是错误）
- **忽略业务重要性**：熵权只反映数据离散度，不反映业务重要性
- **标准化不统一**：正向 (x-min)/(max-min)，负向 (max-x)/(max-min)
- **值不在 [0,1]**：标准化后所有值必须在 [0, 1]

## 组合权重（AHP + 熵权）

当既想利用专家经验，又想利用数据信息时：
```
组合权重 = α × AHP权重 + (1-α) × 熵权
```
α 通常取 0.5，或根据专家信心调整。
