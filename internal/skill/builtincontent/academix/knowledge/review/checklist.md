# 审稿检查清单

## 方法合理性
- [ ] 假设是否合理、是否必要
- [ ] 模型是否适用于该问题
- [ ] 求解算法是否合适
- [ ] 约束条件是否完整
- [ ] 多目标是否处理了量纲

## 代码正确性
- [ ] 结果是否可复现（固定种子）
- [ ] 约束是否满足（重新代入验证）
- [ ] 数值是否与论文一致
- [ ] 整数变量是否正确处理
- [ ] 是否防数据泄露

## 论文质量
- [ ] 摘要覆盖所有子问题
- [ ] 公式解释符号含义
- [ ] 图表有引导和解释
- [ ] 参考文献真实存在
- [ ] 无内部文件名/脚本名泄露

## 创新性
- [ ] 与已有工作相比有何不同
- [ ] 贡献是否明确
- [ ] 局限性是否诚实说明

## 评分模板
```
- 方法合理性：X/10
- 代码正确性：X/10
- 论文质量：X/10
- 创新性：X/10
- 综合评分：X/10
```
